# AI Business Platform

An AI-powered hospitality operations platform. The long-term direction is to help hospitality businesses coordinate guest communication and daily operations through one configurable workspace.

## Current milestone

This repository starts with a responsive dashboard prototype. It uses sample data only. No real guest messages, bookings, hotel systems, or AI model are connected yet.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS 4
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Product development principles

1. Validate real operational problems with hospitality businesses.
2. Build a narrow workflow that solves one expensive or frequent problem.
3. Keep each business configurable without maintaining a separate codebase.
4. Add integrations and AI actions only after the workflow and permissions are clear.
5. Protect guest data and never commit API keys or credentials.

## Status

Prototype stage. Metrics, tasks, conversations, and assistant responses are illustrative demo content, not live hotel data.
